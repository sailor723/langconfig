职务说明书说的，就是公理

业务跟单（JD：2 年以上、跟单/Excel/行政任一、高中及以上）

:skillsFor_业务跟单 ≡ ( :OrderTracking ⊔ :SpreadsheetSoftware ⊔ :AdminSkill )
:matches_业务跟单 ≡ :Candidate
    ⊓ (:hasSkill some :skillsFor_业务跟单)
    ⊓ (:yearsExperience some xsd:integer[>= 2])
    ⊓ (:educationRank  some xsd:integer[>= 2])
为什么是并集实测
JD 写的是这个岗位会用到哪些工具要求「全部命中」时，277 人里只剩 1 个合格
「至少命中一类」才是短名单的意思改成并集后 48 人合格（: 见步骤 5）

阈值只有 DL 推理机能判。纯 Python 的 OWL 2 RL（owlrl）会把含 xsd:minInclusive 的类判成空集；本仓库用 HermiT。
