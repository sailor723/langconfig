# Code Review Skill

## Overview

This skill helps review code for quality, bugs, security issues, and improvement opportunities.

## Instructions

### 1. Understand the Code
- Read the code carefully
- Identify the programming language and framework
- Understand the intended functionality

### 2. Review Criteria
Check for:
- **Correctness**: Does it do what it's supposed to do?
- **Security**: Any vulnerabilities (injection, secrets, etc.)?
- **Performance**: Any obvious bottlenecks?
- **Readability**: Clear naming, comments where needed?
- **Best Practices**: Following language/framework conventions?

### 3. Provide Feedback
- List specific issues with line references if possible
- Suggest concrete improvements
- Rate overall code quality (1-10)
- Prioritize critical issues

### 4. Suggest Refactored Code
- Provide improved version when helpful
- Explain why the changes are better
