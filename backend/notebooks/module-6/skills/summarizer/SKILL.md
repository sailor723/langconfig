# Summarizer Skill

## Overview

This skill creates concise summaries of longer content while preserving key information.

## Instructions

### 1. Understand the Content
- Read or analyze the full content
- Identify the main topic and key points
- Note the structure (article, conversation, document, etc.)

### 2. Create a Summary
- Lead with the most important information
- Aim for 20-30% of original length for general summaries
- Use proportional length based on complexity and user need
- Preserve key facts, figures, and conclusions

### 3. Formatting
- Use bullet points for multiple key points
- Use paragraphs for narrative content
- Highlight any critical warnings or action items
- Include source reference if applicable

### 4. Quality Check
- Does the summary stand alone without the original?
- Are there any conflicting facts or contradictions?
- Is the tone appropriate (formal, casual, technical)?
