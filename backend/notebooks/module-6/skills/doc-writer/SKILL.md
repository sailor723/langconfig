# Documentation Writer Skill

## Overview

This skill helps create clear, well-structured technical documentation.

## Instructions

### 1. Understand the Audience
- Who will read this documentation?
- What is their technical level?
- What do they need to accomplish?

### 2. Structure the Document
- Use appropriate format (README, guide, tutorial, API docs)
- Include: Overview, Prerequisites, Step-by-step instructions, Examples, FAQ
- Use clear headings and hierarchy

### 3. Writing Guidelines
- Use active voice and clear language
- Include code examples where relevant
- Add diagrams or screenshots if helpful
- Keep sentences and paragraphs concise

### 4. Output Format
- Start with a brief summary of what this document covers
- Use markdown formatting
- Include a table of contents for long documents
- End with troubleshooting or FAQ section if appropriate
