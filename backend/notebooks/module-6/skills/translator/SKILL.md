# Translator Skill

## Overview

This skill handles language translation requests using the model's built-in multilingual capabilities.

## Instructions

### 1. Identify Source and Target Languages
- Determine what language the input is in
- Identify the target language from the request
- If not specified, ask for clarification or default to English

### 2. Translate Accurately
- Provide a direct, natural translation
- Preserve the tone and formality level of the original
- Maintain idiomatic expressions where possible
- Keep technical terms accurate

### 3. Handle Special Cases
- Unknown/unclear words: note them and provide best guess
- Very long text: translate in chunks, maintain context
- Informal/slang: try to match register in target language

### 4. Present the Result
- State both source and target languages
- Provide the translation clearly
- Note any nuances or alternative translations if relevant
