## 二、字段契约

### 2.1 三层结构

```
会议 (1) ── 议题 (N) ── 决议事项 (M)     N ≤ M
```

现有数据只有 **会议** 和 **决议事项** 两层，**议题层缺失**——这是「重复议题识别」做不出来的根本原因。

### 2.2 会议层

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| meeting_id | string | 是 | 厂区+年+月+3位流水，如 `HQ2605001` |
| code | enum | 是 | HQ / SW / OS / NB |
| title | string | 是 | 会议名称 |
| meeting_type | enum | 是 | 见 2.5 归一化表 |
| date | date | 是 | 会议日期 |
| start_time / end_time | time | 否 | 时段 |
| duration_min | int | 是 | 时长，缺失时按 时段 推算 |
| convener | string | 是 | 主导人 |
| recorder | string | 否 | 记录人 |
| attendees | string[] | 是 | 参会人员（拆分后） |
| location | string | 否 | 场所 |
| minutes_full | text | **新增** | 纪要全文，来自平台 A |
| minutes_source | enum | **新增** | `asr` 自动转写 / `manual` 人工整理 / `none` |
| asr_confidence | float | **新增** | 转写置信度（若平台 A 提供） |
| repeat_no | int | 是 | 同主题第几次召开（相似度 ≥70% 且同主导人累计） |
| status | enum | 是 | 进行中 / 已结案 |

### 2.3 议题层（新增）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|

| discussion | text | 否 | 讨论摘要（3–6 句） |

| problem_key | string | **是** | **问题指纹**，见 2.6，重复识别的主键 |

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|

### 2.5 会议类型归一化表

原始 14 种标签中，组合式标签明显是「下拉无法单选」造成的，`例会/工作汇报`(257) 和 `例会/临时会议`(7) 必须拆。

| 原始值 | 归一化 | 规则 |
|---|---|---|
| 例会、周会 | 周会 | 固定周期 |
| 例会/工作汇报 | 周会 | 取第一段 |
| 工作汇报、专项汇报、例会/工作汇报 | 专题会 | 非固定周期、有明确议题 |
| 例会/临时会议、临时 | 临时会 | |
| 业绩复盘、风险预警、方案共创、项目会议 | 专题会 | |
| 培训 | 培训 | |
| **面试、接待客户** | **非会议** | **不计入会议统计** |
| 其他、会议 | 待定 | 需人工补 |

> 面试 148 场、接待客户 39 场，合计 187 场，占 5.2%——混在会议统计里会污染时长与人时。

### 2.6 问题指纹（重复议题识别的主键）

重复识别**不能**用文本相似度，必须归一化到「对象 + 问题类型」：

```
problem_key = {对象类型}:{对象编号}:{问题类型}
例：MAT:N15:MATERIAL_DEFECT     （N15 PCB 板材料不良）
    MAT:3122:MATERIAL_DEFECT    （3122 纤维管胶丝）
    WO:ZX725104:MACHINE_MISMATCH（机台不适配）
    WO:ZX499944:SHORTAGE        （欠料）
```

**对象类型**：MAT（物料/机种）、WO（工单）、MOLD（模具）、EQP（机台）、SYS（系统/流程）
**问题类型**：SHORTAGE 欠料 / MATERIAL_DEFECT 来料不良 / MACHINE_MISMATCH 工装不适配 / REWORK_HOURS 返工工时未结 / QUALITY_NG 品质异常 / DELAY 交期延迟 / STD_MISSING 标准缺失

**本场会的真实重复案例**：议题 1 与议题 4 都指向 `MAT:N15:REWORK_HOURS`（返工工时未结），但现有数据里它们是两条互不相关的事项——因为中间缺了议题层，也没有指纹。
