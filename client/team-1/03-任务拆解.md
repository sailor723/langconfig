# 会议分析平台 · 任务拆解

> 版本 v1.0 ｜ 2026-11-13 ｜ 上游：[02-规格.md](02-规格.md)
> 每个任务是一条完整可验证的纵切路径（数据 + 逻辑 + 界面 + 测试），按切片顺序推进，切片内可并行。

---

## 任务拆解

### 切片一 · 能登录、能看到真数（整片可上线）

**1. 可登录的骨架纵切**
- **Blocked by**：无
- **交付内容**：用账号密码登录，进入一页「集团总览」，看到来自真实《会议汇总》的一个数字——会议人时投入，可切换本月 / 本季 / 本年 / 近 12 个月。
- **验收标准**：
  - [ ] 一条命令启动后，数据库自动迁移到最新，页面可打开
  - [ ] 错误密码提示明确，连续 5 次失败锁定 5 分钟
  - [ ] 页面显示的人时数字可用独立 SQL 复算，误差为 0，且显示「这个数怎么算的」
  - [ ] 期间切换后数字变化，环比计算正确
  - [ ] 退出后回到登录页，刷新不会恢复会话

**2. 组织架构与四级权限**
- **Blocked by**：任务 1
- **交付内容**：导入组织架构名单（人名 → 厂区 → 部门），四种角色登录后看到不同数据范围：集团总负责人看四厂、厂长看本厂、部门负责人看本部门、当事人只看本人相关。
- **验收标准**：
  - [ ] 厂长手动改 URL 参数请求他厂，返回空集，页面显示「当前范围无数据」而不是报错页
  - [ ] 部门负责人看不到本厂其他部门的会议
  - [ ] 当事人只看到本人为责任人或主导人的会议
  - [ ] 集团总负责人的合计等于各厂之和
  - [ ] 非管理员访问管理接口返回 403

**3. 《会议汇总》导入：别名识别 + 校验报告**
- **Blocked by**：任务 1
- **交付内容**：上传 CSV / XLSX，系统自动识别表头别名，把「一行 = 一条决议」聚合成「一场会议」，并给出导入报告：识别行数、跳过行数及原因、警告清单。
- **验收标准**：
  - [ ] 导入 3562 行真实文件，聚合出的场次与手工统计一致
  - [ ] 同一文件导入两次，数据不翻倍
  - [ ] 表头改成「会议主题 / 开会日期 / 类型」仍能识别
  - [ ] 缺「厂区 / 日期 / 会议名称」任一列时，明确报出缺哪列
  - [ ] 无法识别的厂区代码、无法解析的日期，逐行列入警告，不静默丢弃

**4. 数据清洗与归一化**
- **Blocked by**：任务 3
- **交付内容**：会议类型从 14 种归一到 6 类 + 非会议；参会人按 `、,，/` 拆分去重；「面试 / 接待客户」不计入会议统计；无责任人的事项归口到主导人部门并打「未指派」标记；时长异常值标记。
- **验收标准**：
  - [ ] 「例会 / 工作汇报」归入周会，不再作为独立类别出现在任何列表
  - [ ] 「面试」「接待客户」不出现在会议场次与人时统计里，可在配置里切回来
  - [ ] 一场 9 人参会的会议显示 9 人
  - [ ] 无责任人的事项在列表带「未指派」标记，且能看到归口到了哪个部门
  - [ ] 时长 > 180 分钟的 59 行被标为异常值，可一键排除

**5. 集团总览五 KPI**
- **Blocked by**：任务 2、任务 4
- **交付内容**：首屏五个指标——会议人时投入、决议闭环天数中位数、无责任人占比、重复会议场次、佐证齐全闭环率；每个指标带四厂分行与环比。
- **验收标准**：
  - [ ] 五个数字与独立 SQL 复算一致
  - [ ] 每个指标都能点开看算法说明
  - [ ] 完成率、超期率不出现在首屏
  - [ ] 样本不足时显示「样本偏少，暂不出环比」，不显示错误百分比

### 切片二 · 能看分厂、能钻进会议

**6. 分厂视图**
- **Blocked by**：任务 5
- **交付内容**：进入某个厂，看到本厂 KPI、部门成绩表（场次 / 事项 / 闭环率 / 无责任人占比 / 效能指数）、本厂与集团平均的对比。
- **验收标准**：
  - [ ] HQ / SW / OS 三厂数字之和等于集团总览
  - [ ] NB 显示「尚未接入」空态，不显示因 0 造成的假对比
  - [ ] 部门行可点击进入该部门的会议列表
  - [ ] 厂长看到的部门表只有本厂部门

**7. 会议明细与纪要全文降级**
- **Blocked by**：任务 6
- **交付内容**：点任一场会，看到会议信息、议题列表、每条决议的责任人 / 期限 / 状态；纪要全文有则展示，无则显示「纪要未接入」并允许手工补录议题。
- **验收标准**：
  - [ ] 一场 9 条决议的会正确显示 9 条，不合并、不丢失
  - [ ] 纪要为空时页面不报错，议题区降级为「一事一项」
  - [ ] 手工补录议题后，该会议的议题数与重复识别结果随之更新
  - [ ] 决议行可跳到「我的任务」中对应项

**8. SQCDS / 4M1E 十维归并与下钻**
- **Blocked by**：任务 5
- **交付内容**：两张各五维的维度卡，显示占比、事项数、完成情况；点卡进入该维度下的会议清单。
- **验收标准**：
  - [ ] 十个维度事项数之和等于总事项数，不重不漏
  - [ ] 归类不出的议题进入「未归类」，不强行分配
  - [ ] 维度卡上的场次与下钻清单行数一致

### 切片三 · 闭环能真正落地

**9. 佐证四件套上传**
- **Blocked by**：任务 7
- **交付内容**：责任人在任务页上传四类佐证（标准 / 培训记录 / 执行前后对比 / 监督验证），每类一个文件，显示已传 / 未传。
- **验收标准**：
  - [ ] 四类各自独立，缺哪类明确显示哪类
  - [ ] 上传后刷新仍在，文件可下载
  - [ ] 超 50MB 或 exe / zip 等格式被拒，提示明确
  - [ ] 非责任人本人不能为该任务上传

**10. 规则引擎 AI 审核**
- **Blocked by**：任务 9
- **交付内容**：点「AI 审核」按规则打分（人 40 + 事 60），给出通过 / 不通过与具体原因；结论落库，任何人可复算。
- **验收标准**：
  - [ ] 同一份数据重复审核，分数完全一致
  - [ ] 缺佐证时列出缺哪几类
  - [ ] 截止时间早于会议时间判为逻辑异常并拒绝
  - [ ] 阈值改动后重算结果随之变化

**11. 上级审核与结案状态机**
- **Blocked by**：任务 10
- **交付内容**：AI 通过后提交上级，上级可通过 / 驳回；佐证四件套 + AI + 上级三者齐备才能结案，结案后事项锁定。
- **验收标准**：
  - [ ] 缺任一件佐证，结案按钮不可用并说明缺什么
  - [ ] AI 未通过时提交上级被拒
  - [ ] 上级驳回后任务回到进行中
  - [ ] 三者齐备结案成功，记录结案人与时间
  - [ ] 结案后再上传佐证被拒

### 切片四 · 回答「会议多好还是少好」

**12. 统计分析：四象限 + 效果链漏斗**
- **Blocked by**：任务 5
- **交付内容**：首屏四象限（异常多 / 少 × 效能高 / 低）+ 一句话口径；效果链漏斗（发现 → 对策 → 闭环 → 固化）。
- **验收标准**：
  - [ ] 四象限的判定规则在页面上可查
  - [ ] 漏斗各段之和与上游总数一致，差值有解释
  - [ ] 期间切换后两期对比正确，样本不足不出环比

**13. 主体成绩：部门 / 个人效能指数**
- **Blocked by**：任务 12、任务 11
- **交付内容**：部门表与个人表，列含场次、事项、闭环率、责任闭环指数、效能指数、单位产出（已闭环事项数 ÷ 会议人时）。
- **验收标准**：
  - [ ] 效能指数可展开看到分子与分母
  - [ ] 事项少于 5 项的个人只显示趋势，不进排名
  - [ ] 个人表默认按效能升序（先看差的），可切换
  - [ ] 部门表数字与其成员之和一致

### 切片五 · 重复议题能被认出来

**14. 纪要内容接入：现有字段 + 接口预留**
- **Blocked by**：任务 3
- **交付内容**：把《会议汇总》的「会议纪要」字段作为纪要内容接入——同一会议的 N 条纪要按序合并成该会议的纪要区；同时在配置页预留平台 A 接口（地址 / 间隔 / 字段映射），未配置时显示「接口未启用」，配置后可覆盖现有内容。
- **验收标准**：
  - [ ] 一场 9 条决议的会议，纪要区按序号顺序显示 9 条
  - [ ] 接口未配置时页面完全正常，只标注「来源：导出文件」
  - [ ] 用 mock 接口配置后可拉取覆盖，标记「来源：接口同步」
  - [ ] 重复同步不产生重复纪要，接口失败沿用上一份并提示

**15. 问题指纹与重复议题识别**
- **Blocked by**：任务 4、任务 7
- **交付内容**：从「会议纪要」短文本中抽取「对象类型 : 对象编号」与问题类型，同一对象聚合成「关联事项」，同对象 + 同问题类型第 N 次出现时标出「第 N 次上会」。
- **验收标准**：
  - [ ] 同一对象（如 N15 PCB 板）的多条事项在对象页聚合显示，并标注各自问题类型
  - [ ] 同对象 + 同问题类型第 2 次出现，标「第 2 次上会」
  - [ ] 不同物料、不同问题类型不会被误合并
  - [ ] 抽不出指纹的进入「待确认」队列，人工可指定对象与类型
  - [ ] 重复议题数在总览与重复页一致

**16. 会议知识库检索**
- **Blocked by**：任务 15
- **交付内容**：按主题、决议内容、责任人跨厂检索历史结论，结果卡显示第 N 次上会标记，可跳回原会议。
- **验收标准**：
  - [ ] 检索范围随角色收窄，厂长搜不到他厂
  - [ ] 搜「N15」能同时命中议题与决议两条路径
  - [ ] 结果可点回原会议详情，定位正确

### 切片六 · 能提醒、能带走、能配置

**17. 预警与订阅**
- **Blocked by**：任务 11
- **交付内容**：红（超期）/ 黄（临期）预警列表；连续超期自动升级上级；夜间与周末静默；同一任务只提醒一次。
- **验收标准**：
  - [ ] 超期变红、临期变黄，边界按配置的临期天数
  - [ ] 同一任务第二次进入预警不再重复提醒
  - [ ] 22:00–08:00 与周末不发送，转次日 08:00 汇总
  - [ ] 升级规则触发后，上级收到一条汇总而非多条

**18. 报表导出与平台配置**
- **Blocked by**：任务 13
- **交付内容**：导出月度 Excel（指标页 + 明细页）；配置页可改阈值、类型归一化表、别名规则，查看权限矩阵与审计日志。
- **验收标准**：
  - [ ] 导出文件 Excel 直接打开，中文不乱码
  - [ ] 改阈值后相关指标立即按新阈值重算
  - [ ] 改归一化表后，「面试」是否计入会议可切换
  - [ ] 审计日志能查到「谁在什么时候把哪条任务结案」

**19. 期间自适应（归档延后）**
- **Blocked by**：任务 18
- **交付内容**：期间选择器由数据驱动，只展示实际有数据的月份（当前 9 个月）；「本年」按实际覆盖区间统计而非 365 天；归档功能以「未启用」状态列出，等数据攒满 12 个月再启用。
- **验收标准**：
  - [ ] 期间下拉按数据生成，新增月份自动出现，不出现无数据的空月份
  - [ ] 「本年」统计范围等于实际覆盖区间，页面注明起止月份
  - [ ] 归档以「未启用」状态出现在配置页，并注明启用条件
  - [ ] 数据跨过 12 个月后，归档开关可直接打开生效
